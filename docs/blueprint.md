# **App Name**: LinkDrop

## Core Features:

- Hero Section: Display a prominent heading and brief introduction about the page.
- Link Buttons: Create buttons linking to https://spollock.ca, https://github.com/srepollock, and https://linkedin.com/in/srepollock.
- AdSense Integration: Include AdSense script snippet in the page.
- AdSense Ad Slot: Configure an ad slot component where AdSense advertisements will display, using the client id "ca-pub-8650073157913510".

## Style Guidelines:

- Primary color: Dark Blue (#303030) for a dark mode look.
- Background color: Dark Gray (#121212), providing a dark backdrop.
- Accent color: Light Blue (#ADD8E6) to highlight the buttons, creating visual interest and focus.
- Body text and headings: 'Inter' (sans-serif) for clear readability and modern appeal.
- Simple, clean layout centered on the screen for easy navigation.
- Subtle hover animation on the buttons.
